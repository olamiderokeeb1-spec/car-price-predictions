# Car Price Prediction Using Machine Learning

## Overview
This project predicts car prices using machine learning models such as Random Forest, XGBoost, Decision Tree, and Linear Regression.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Model Comparison
- Streamlit Deployment

## Technologies Used
- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit

## Best Model
Random Forest achieved the best performance with:
- R² Score: 0.725
- MAPE: 18.7%

## Run Locally
streamlit run streamlit_app.py
